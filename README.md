# ArchCalc AI — первая версия прототипа КТ3

## Что уже реализовано
- Ввод запроса на естественном языке; разбор запроса реальной Gemini-моделью **после** подключения своего API-ключа.
- Вычисление площади, объёма и масштаба в Python (проверенные вычисления в `calculations.py`).
- AI-объяснение вычислений **после** подключения API.
- Собственная небольшая база формул (`knowledge_base.json`).
- Ручной режим проверки формул без API — не является ИИ и не заменяет основную демонстрацию.

## Шаг 1. Запуск на вашем компьютере
Установите Python 3.10+.

Откройте командную строку/PowerShell в папке проекта и выполните:

```shell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откроется сайт в браузере по адресу `http://localhost:8501`.

## Шаг 2. Подключение Gemini
1. Откройте Google AI Studio: https://aistudio.google.com/apikey
2. Выберите модель, для которой у вашего проекта **действительно доступен API** (и бесплатный тариф, если нужен).
3. Получите личный API-ключ. Не отправляйте его в общие чаты и не загружайте на GitHub.
4. Для локального запуска создайте `.streamlit/secrets.toml` по образцу `.streamlit/secrets.toml.example` с настоящим ключом.
5. При необходимости измените `GEMINI_MODEL` на актуальный ID модели из AI Studio.
6. Перезапустите сайт и проверьте кнопку «Рассчитать через ИИ».

Примечание: доступ к моделям и лимиты меняются. По умолчанию вписан `gemini-3.5-flash-lite`, но доступность для конкретного аккаунта не подтверждалась.

## Шаг 3. Публичная ссылка для преподавателя
1. Создайте репозиторий на https://github.com/ и загрузите туда папку проекта **без** `.streamlit/secrets.toml`.
2. Откройте https://share.streamlit.io и войдите через GitHub.
3. Нажмите создать/Deploy app, укажите ваш репозиторий и файл `app.py`.
4. В настройках Secrets вставьте `GEMINI_API_KEY` и `GEMINI_MODEL`.
5. Нажмите Deploy и получите ссылку вида `https://...streamlit.app`.
6. Проверьте эту ссылку с чужого устройства, введя **другие числа**, и убедитесь, что ИИ действительно понимает запрос.

## Что вставить в шаблон КТ3
- «Форма прототипа»: веб-приложение на Python/Streamlit.
- «Ссылка на прототип»: реальная ссылка с Streamlit Community Cloud.
- «Тестовый доступ»: не требуется, если сайт открывается без логина.
- «ИИ»: реальная модель Gemini, которую подключили, и основной промпт из функции `interpret_request`.
- «База знаний»: `knowledge_base.json`, три базовые формулы.
- «Скриншоты»: экран приложения, ввод запроса, интерпретация ИИ, результат, объяснение.
- «Готовность функций»: отмечайте только то, что реально удалось запустить.
